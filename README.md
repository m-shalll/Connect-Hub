# 📱 Java Social Media App

A simple social media platform built in **Java**, featuring:

- 🧵 Multi-threaded **chatting system**
- 🖥️ **Swing-based GUI**
- 💾 Data persistence using **JSON files**

---

## 📌 Features

- 👥 User registration and login
- 💬 Real-time chatting using Java Threads
- 🪟 Interactive UI built with Swing
- 💾 Save/load user data and messages in JSON format
- ✅ Thread-safe operations for simultaneous messaging

---

## 🛠️ Technologies Used

| Technology | Description                      |
|------------|----------------------------------|
| Java       | Core programming language        |
| Swing      | GUI components                   |
| Threads    | Multi-user chat handling         |
| JSON       | Data persistence (users/messages)|
